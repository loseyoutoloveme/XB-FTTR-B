帮助说明

【功能说明】

本工具用于计算PON网络的光功率预算，判断组网配置是否满足光功率要求。

【计算模型】

一级分光:

上行光功率 = 光网关发送功率
接收光功率 = 上行光功率 - 直连损耗 - 1dB(连接器损耗)

二级及后续分光:

上行光功率 = 上一级上行光功率 - (上一级级联损耗=0 ? 直连损耗 : 级联损耗)
接收光功率 = 上行光功率 - 直连损耗 - 1dB(连接器损耗)

【分光器说明】

无源分光器 (OSPL系列):

  • 级联损耗 = 0
  • 支持1x2, 1x4, 1x8, 1x16, 1x32, 1x64

有源分光器 (UFD系列):

  • 级联损耗 > 0
  • 可多级级联扩展
  • 支持1x5, 1x9

【合格标准】

接收灵敏度 + 2dB < 接收光功率 < 过载功率 - 2dB

其中2dB为预留余量，保证网络稳定运行。

【使用步骤】

  1. 选择光网关型号（确定发送功率）
  2. 选择光AP/光交换型号（确定接收要求）
  3. 配置ODN网络（选择各级分光器）
  4. 点击"开始计算"查看结果
  5. 检查各分光级别是否为"合格"
